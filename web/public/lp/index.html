既存のシステムやアナログな運用では防げない課題に直面していませんか？

人

動態管理と証跡の限界

手書き日報や自己申告では、記入漏れや事後記入を防げない。「本当にそこにいたか」を証明できない。

→ タグへのタッチ時刻と場所を自動で記録。暗号タグなら撮影したURLでのなりすましも拒否。

設備

非効率とヒューマンエラー

→ かざした設備のカルテとマニュアルが即表示。資格がなければ操作許可を出さず、手順は順番通りにしか進めない。

Core Technology

NFC × BLE のハイブリッド安全管理

NFC仮想ビーコン

「意図」の証明と確かなロケーション

電源不要でどこにでも貼れるNFCシールを現場に配置。数センチまで近づけて「意図的にかざす」動作を条件にすることで、離れた場所からの打刻を防ぎます。1枚のタグが、状況に応じて巡回の通過点・点検の入口・設備の操作許可（バーチャルキー）・単独作業の生存確認として働きます。

  • ● 暗号タグ（NTAG 424 DNA）はタッチのたびに使い捨ての署名を発行。撮影したURLの再利用を拒否します
  • ● 記録ごとに「証明レベル（高・中・低）」を残し、監査で根拠を示せます
  • ● NFC非対応の端末向けにQRコードも併記（証明レベル低として区別）

管理画面から印刷できるタグ用ラベル（QRコード付き）

BLE接近検知

「空間」の動的なハザードを感知

作業員が携帯する小型BLEタグの電波を、フォークリフトなど重機側の受信機が検知。危険距離まで近づいた瞬間に、通信を待たずその場で警報を鳴らします。検知の記録は後からクラウドへ送られ、どの重機・どの時間帯・どの作業員でヒヤリハットが多いかを分析できます。

  • ● 通信が途切れても警報は止まりません
  • ● 無資格者の運転席タッチや起動を検知して管理者へ通知
  • ● 車両の減速・停止との連動は、安全評価を経て順次対応予定です

Features

現場の「確認」をまるごとデジタルに

すべての機能を1つのサービスで。必要なものから使い始められます。

巡回ルート

地点タグを順にかざして巡回を記録。順番の強制、目安時間、未通過地点の確認ができます。

設備カルテと点検

かざすと型式・点検履歴・マニュアルPDFを表示。チェック項目と写真で点検を記録し、期限切れを知らせます。

バーチャルキー

有効な資格を持つ人だけに設備の使用を許可。使用中の人がいれば重複を防ぎ、無資格の操作は管理者に通知。

手順インターロック

「電源遮断 → 検電 → 作業開始」のように、決められた順番でタグをかざさないと次に進めません。

単独作業の生存確認

一人作業の間、一定間隔でタグにかざして応答。応答がなければ管理者へ自動でアラートを送ります。

ヒヤリハット報告

スマホから内容と写真をその場で報告。重大度に応じてダッシュボードと通知に即反映されます。

リアルタイムダッシュボード

現場のタッチ、未対応アラート、単独作業者の残り時間、設備の使用状況をリアルタイムに表示。

分析・ヒートマップ

ゾーン別・曜日×時間帯・作業員別・重機別にヒヤリハットと動線を可視化。点検の所要時間も分析します。

月次報告書・CSV

元請け・ビルオーナー向けの月次報告書を自動作成。印刷・PDF保存、記録のCSV出力にも対応。

メール・LINE通知

生存確認の無応答、接近、無資格操作、点検異常をメールと現場のLINEグループへ。宛先と種類を選べます。

オフライン対応

地下や機械室など圏外でも記録を端末に保存し、電波が戻ると自動で送信します。

タグの登録・交換がかんたん

届いたタグは貼った場所でかざして登録。破損時は新しいタグに交換するだけで巡回・手順の設定を引き継ぎます。

安心して使っていただくために

常時追跡しません

位置が記録されるのは、作業員が自らタグにかざした時と、重機に近づいた時だけ。GPSで常に居場所を追うことはありません。

改ざんしにくい記録

記録はクラウドに保存され、変更の操作は監査ログに残ります。暗号タグは使い捨ての署名でなりすましを防ぎます。

権限と通信の保護

通信はすべて暗号化。作業員・マネージャー・管理者の権限を分け、運営側のログインには二段階認証を必須にしています。

よくある質問

専用アプリのインストールは必要ですか？

不要です。タグにかざすとスマホのブラウザで画面が開きます。ホーム画面に追加すればアプリのように使えます。

iPhoneでも使えますか？

使えます。iPhoneは画面を点けた状態で本体上部をタグに近づけ、表示された通知をタップします。Androidは本体背面をかざします。NFC非対応の端末はラベルのQRコードでも記録できます。

電波が届かない地下や機械室でも記録できますか？

できます。記録は端末に一時保存され、電波が戻ると自動で送信されます（保存から7日以内）。

タグの電池交換は必要ですか？

NFCタグは電池を使いません。電池が必要なのは、接近検知を使う場合の作業員の携帯タグと重機側の受信機だけです。

タグをはがされたり、写真を撮られて不正に打刻されませんか？

暗号タグはタッチのたびに使い捨ての署名を出すため、撮影したURLでは記録できません。標準タグやQRコードでの記録は「証明レベル低」として区別され、QRでの記録を禁止する設定もあります。

タグが壊れたらどうなりますか？

新しいタグを貼り、管理画面で「交換」するだけです。巡回ルートや作業手順の設定は自動で引き継がれます。

重機を自動で止めることはできますか？

現在は、接近時に重機側で警報を鳴らし、記録と通知を行います。車両の減速・停止との連動は、機能安全の評価を経て対応を進めています。

支払い方法と契約期間は？

月額制で、毎月請求書をお送りします（銀行振込）。最低契約期間はなく、トライアル終了後に自動で課金されることもありません。
