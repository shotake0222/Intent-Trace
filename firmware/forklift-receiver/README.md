# 重機側 BLE 接近検知レシーバー（リファレンス）

作業員が携帯する BLE タグ（iBeacon 形式・社員証一体型など）を ESP32 で受信し、
**ネットワークを介さず基板内だけで** 距離判定 → ブザー／回転灯（→ フェーズ3で減速入力）を行います。
クラウド（Intent-Trace）へは接近ログを後からバッチ送信するだけなので、通信断・クラウド障害でも安全機能は止まりません。

## 構成
- ESP32 DevKit（Arduino core 3.x）
- ライブラリ: NimBLE-Arduino 2.x, ArduinoJson 7.x
- 出力: ブザー（GPIO25）、回転灯リレー（GPIO26）、減速入力（GPIO27・既定無効）、起動許可表示（GPIO14・既定無効）

## セットアップ
1. 管理画面「IoTデバイス」で *重機側 BLE レシーバー* を登録し、表示された認証情報を控える
2. `config.example.h` を `config.h` にコピーし、Wi-Fi・API_BASE・認証情報・ビーコンUUIDを設定
3. 作業員ごとの BLE タグの `major:minor` を、管理画面「作業員・資格」の *携帯BLEタグ ID* に登録
4. 現場で実測してしきい値（`CAUTION_M` / `DANGER_M` / `PATH_LOSS_N`）を調整

## 注意
- RSSI による距離推定は遮蔽物・向き・反射で大きくぶれます。しきい値は安全側（遠め）に設定し、必ず現地で検証してください。
- `ENABLE_SLOWDOWN` による車両制御は、車両メーカーの承認と機能安全評価（ISO 13849 等）を前提とするフェーズ3機能です。
- 本スケッチは動作検証済みの製品ファームウェアではなく、API 連携と責務分離を示すリファレンスです（本リポジトリの CI ではコンパイルしていません）。
